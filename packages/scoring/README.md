# @wx/scoring — 供應商季度評比評分引擎

整個系統的**計算真相來源**。純函式、框架無關，前端與後端都直接引用這一份，取代現有散落四處（前端 service／元件／匯出、後端 index.js）且互相不一致的複製邏輯。

## 內容
- `src/constants.ts` — 所有門檻／權重／階梯（改一處即全系統生效）
- `src/index.ts` — 評分函式：CAR、LAR、品質、交期、等級、單季降級、跨季連續降級、綜合評比
- `src/types.ts` — 輸入／輸出型別
- `src/scoring.test.ts` — 單元測試（鎖住每條公式）
- `scripts/characterize.mjs` — 對拍測試：對真實 DB 逐筆比對

規格文件：[docs/評分規則_現況萃取.md](../../docs/評分規則_現況萃取.md)

## 指令
```bash
npm install
npm test          # 單元測試（37 個）
npm run typecheck # 型別檢查
npx tsc           # 編譯到 dist/（對拍腳本需要）

# 對拍（需先啟動 DB 通道：專案根目錄 .\db-tunnel.ps1 start）
node scripts/characterize.mjs
```
