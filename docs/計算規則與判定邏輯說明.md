## SQM/VQM 模組

### 一、月評核計算邏輯

#### 1.1 品質評鑑計算 (`calculateQualityReport`)

**前置條件：**
- 如果 `receivedBatches === 0`，所有計算欄位返回 `null`

**計算公式：**

1. **品質基數評分 (totalBaseScoreB)**
   ```
   品質基數評分 = max(0, 90 - 2×產線(ARR) - 2×IQC(LRR) - 10×客訴(ExternalCAR) - 5×未準時回覆件數(UntimelyResponseCCR))
   ```
   - 最小值為 0

2. **品質-品管鑑定總分 (qualityAssessmentScoreC1)**
   ```
   品質-品管鑑定總分 = 品質基數評分 + 其他(Others)
   ```
   - 四捨五入至小數點後 2 位

3. **品質-品管鑑定分數 (qualityAssessmentScoreC) - 權重 70%**
   ```
   品質-品管鑑定分數 = 品質-品管鑑定總分 × 0.7
   ```
   - 四捨五入至小數點後 2 位

#### 1.2 採購評鑑計算 (`calculatePurchaseReport`)

**前置條件：**
- 如果 `receivedBatches === 0`，所有計算欄位返回 `null`

**計算公式：**

1. **採購評鑑分數 (purchaseAssessmentScoreA)**
   ```
   採購評鑑分數 = max(0, 100 - 5×遲交(LateDelivery) - 5×特採(SpecialApproval) - 100×造成斷線(ProductionLineStop) - 25×產生超額運費(ExcessFreight))
   ```
   - 最小值為 0

2. **採購評鑑分數 (權重 20%) (totalPurchaseAssessmentScoreA)**
   ```
   採購評鑑分數(權重20%) = 採購評鑑分數 × 0.2
   ```
   - 四捨五入至小數點後 2 位

#### 1.3 綜合評鑑計算 (`calculateComprehensiveReport`)

**前置條件：**
- 如果 `qualityAssessmentScoreC === null`，所有計算欄位返回 `null`

**計算公式：**

1. **總品質評分 (totalQualityScore)**
   ```
   總品質評分 = 品質-品管鑑定分數(權重70%)
   ```

2. **交期評分 (deliveryScore)**
   ```
   交期評分 = 採購評鑑分數(權重20%)
   ```

3. **服務評分 (serviceScore)**
   ```
   服務評分 = 品質評鑑的服務分數 + 採購評鑑的服務分數
   ```
   - 四捨五入至小數點後 2 位

4. **考核得分 (assessmentScore)**
   ```
   考核得分 = 總品質評分 + 交期評分 + 服務評分
   ```
   - 四捨五入至小數點後 2 位

5. **降級判定 (downgradeDecision)**
   ```
   降級判定 = (總品質評分 < 56) 或 (交期評分 < 16)
   ```
   - `true` 表示需要降級，`false` 表示不需要降級

6. **等級判定 (grade)**
   - **有降級判定時：**
     - `assessmentScore >= 95` → `B`
     - `assessmentScore >= 85` → `C`
     - `assessmentScore >= 75` → `D`
     - `assessmentScore >= 60` → `D`
     - `assessmentScore < 60` → `E`
   
   - **無降級判定時：**
     - `assessmentScore >= 95` → `A`
     - `assessmentScore >= 85` → `B`
     - `assessmentScore >= 75` → `C`
     - `assessmentScore >= 60` → `D`
     - `assessmentScore < 60` → `E`

### 二、年度評鑑計算邏輯

#### 2.1 月考核平均分數 (monthlyAssessmentSummary)

```
月考核平均分數 = 所有月份考核得分的平均值
```
- 只計算有考核得分的月份
- 四捨五入至小數點後 3 位（後端）或 2 位（前端）

#### 2.2 交易月數 (purchaseTradingMonths)

```
交易月數 = 進料批數 > 0 的月份數量
```

#### 2.3 交易總量 (purchaseTotalQuantity)

```
交易總量 = 所有月份進料批數的總和
```

#### 2.4 年度稽核組件 (auditComponent)

**計算邏輯：**

1. **選擇主稽核分數**
   - 如果 `VDA !== null` 且 `VDA > 0`，主稽核分數 = VDA
   - 否則（沒有 VDA），主稽核分數 = QSA
   - 注意：`VDA = 0` 視為 `null`（VDA 不可能為 0）

2. **與 HSF 取平均值**
   - 有 VDA 時：`auditComponent = (VDA + HSF) / 2`
   - 沒有 VDA 時：`auditComponent = (QSA + HSF) / 2`
   - 只計算非 null 的分項；若 HSF 為空，則僅取 VDA 或 QSA

3. **預設值**
   - 如果都沒有，則 `auditComponent = 0`

#### 2.5 年度分數 (annualScore)

**計算公式：**

```
如果 auditComponent === 0:
  年度分數 = 月考核平均分數 - others

否則:
  年度分數 = (月考核平均分數 × 0.9) + (年度稽核組件 × 0.1) - others
```

- 四捨五入至小數點後 3 位（後端）或 2 位（前端）
- 如果 `monthlyAssessmentSummary === null`，則 `annualScore = null`

#### 2.6 年度等級 (grade)

```
如果 annualScore === null:
  grade = null

否則:
  annualScore >= 95 → A
  annualScore >= 85 → B
  annualScore >= 75 → C
  annualScore >= 60 → D
  annualScore < 60  → E
```

3. **現場稽核** - 需要現場檢查

## OSAT 模組

### 一、月評核計算邏輯

#### 1.1 品質評鑑計算 - 岡山/蘇州 (`calculateOSATQualityReport` / `calculateSuzhouQualityReport`)

**前置條件：**
- 如果 `receivedBatches === 0`，所有計算欄位返回 `null`

**計算公式：**

1. **進料允收率品質評分 (A1) (incomingAcceptanceScoreA1)**
   ```
   進料允收率品質評分(A1) = (進料批數 - 進料退貨批數) / 進料批數 × 100%
   ```
   - 四捨五入至小數點後 2 位

2. **進料允收率品質評分 (總分A) 40% (incomingAcceptanceScoreA)**
   ```
   進料允收率品質評分(總分A) = 進料允收率品質評分(A1) × 0.4
   ```
   - 四捨五入至小數點後 2 位

3. **基礎評分 (B1) 40% (baseScoreB1)**
   ```
   基礎評分(B1) = max(0, 40 - 5×嚴重客訴(CCR件數) - 1×一般客訴(CCR件數) - 3×客訴再發(CCR件數) - 3×集團CAR(CAR件數))
   ```
   - 最小值為 0
   - 四捨五入至小數點後 2 位

4. **基礎評分 (B2) 10% (baseScoreB2)**
   ```
   基礎評分(B2) = max(0, 10 - 5×未準時回覆件數(CCR))
   ```
   - 最小值為 0
   - 四捨五入至小數點後 2 位

5. **基礎評分 (總分B) 50% (totalBaseScoreB)**
   ```
   基礎評分(總分B) = 基礎評分(B1) + 基礎評分(B2)
   ```
   - 四捨五入至小數點後 2 位

6. **品質-品管鑑定分數 (qualityAssessmentScore)**
   ```
   品質-品管鑑定分數 = 進料允收率品質評分(總分A) + 基礎評分(總分B) + 其他(Others)
   ```
   - 四捨五入至小數點後 2 位

7. **品質-品管鑑定分數 (權重 70%) (qualityAssessmentScoreWeighted)**
   ```
   品質-品管鑑定分數(權重70%) = 品質-品管鑑定分數 × 0.7
   ```
   - 四捨五入至小數點後 2 位

#### 1.2 採購評鑑計算 (`calculateOSATPurchaseReport` / `calculateSuzhouPurchaseReport`)

**前置條件：**
- 如果 `receivedBatches === 0`，所有計算欄位返回 `null`

**計算公式：**

1. **OSAT-採購鑑定總分 (purchaseAssessmentScoreA)**
   ```
   OSAT-採購鑑定總分 = max(0, 100 - 5×遲交 - 5×特採 - 100×造成斷線 - 25×產生超額運費)
   ```
   - 最小值為 0

2. **OSAT-採購鑑定分數 (權重 20%) (totalPurchaseAssessmentScoreA)**
   ```
   OSAT-採購鑑定分數(權重20%) = OSAT-採購鑑定總分 × 0.2
   ```
   - 四捨五入至小數點後 2 位

#### 1.3 綜合評鑑計算 (OSAT Monthly Report)

**計算公式：**

1. **總品質評分 (totalQualityScore)**
   ```
   總品質評分 = 品質-品管鑑定分數(權重70%)
   ```

2. **交期評分 (deliveryScore)**
   ```
   交期評分 = 採購評鑑分數(權重20%)
   ```

3. **服務評分 (serviceScore)**
   ```
   服務評分 = 品質評鑑的服務分數 + 採購評鑑的服務分數
   ```
   - 四捨五入至小數點後 2 位

4. **考核得分 (assessmentScore)**
   ```
   考核得分 = 總品質評分 + 交期評分 + 服務評分
   ```
   - 四捨五入至小數點後 2 位

5. **降級判定 (downgradeDecision)**
   ```
   降級判定 = (考核得分 < 60) ? 'Y' : 'N'
   ```
   - 注意：OSAT 的降級判定僅根據考核得分，不考慮總品質評分和交期評分的個別門檻

6. **等級判定 (grade)**
   ```
   考核得分 >= 95 → A
   考核得分 >= 85 → B
   考核得分 >= 75 → C
   考核得分 >= 60 → D
   考核得分 < 60  → E
   ```

### 三、下年度稽核計畫判定邏輯

#### 3.1 判定維度

OSAT 使用三個維度進行判定：
1. **交易月數** (tradingMonths)
2. **交易總量** (totalQuantity)
3. **年度等級** (grade: A/B/C/D/E)

#### 3.2 稽核類型判定規則

**第一步：檢查交易記錄**
```
如果 purchaseTradingMonths === 0 或 null:
  nextYearAuditType = '無採購紀錄'
```

**第二步：根據交易月數和交易總量判定**

**情況 1：交易月數 >= 6 個月**

| 交易總量 | 年度等級 | 稽核類型 |
|---------|---------|---------|
| >= 8000 | A 或 B | 現場稽核 |
| >= 8000 | C/D/E | 現場稽核+製程稽核 |
| >= 8000 | 無等級 | 現場稽核（預設） |
| >= 4000 且 < 8000 | A 或 B | 文件稽核 |
| >= 4000 且 < 8000 | C/D/E | 現場稽核 |
| >= 4000 且 < 8000 | 無等級 | 文件稽核（預設） |
| < 4000 | A 或 B | 免稽 |
| < 4000 | C/D/E | 現場稽核 |
| < 4000 | 無等級 | 免稽（預設） |

**情況 2：交易月數 <= 5 個月**

| 交易總量 | 年度等級 | 稽核類型 |
|---------|---------|---------|
| >= 8000 | 任何等級 | 現場稽核 |
| >= 4000 且 < 8000 | A 或 B | 文件稽核 |
| >= 4000 且 < 8000 | C/D/E | 現場稽核 |
| >= 4000 且 < 8000 | 無等級 | 文件稽核（預設） |
| < 4000 | A 或 B | 免稽 |
| < 4000 | C/D/E | 現場稽核 |
| < 4000 | 無等級 | 免稽（預設） |

#### 3.3 稽核類型選項

OSAT 有 5 種稽核類型：
1. **無採購紀錄** - 無交易記錄
2. **免稽** - 免於稽核
3. **文件稽核** - 需要文件審查
4. **現場稽核** - 需要現場檢查
5. **現場稽核+製程稽核** - 需要現場檢查和製程稽核

## 共通計算邏輯

### 一、年度稽核組件計算 (`getAuditComponent`)

**計算邏輯（SQM 和 OSAT 相同）：**

1. **選擇主稽核分數**
   ```
   如果 VDA !== null 且 VDA > 0:
     主稽核分數 = VDA
   否則:
     主稽核分數 = QSA
   ```
   - 注意：`VDA = 0` 視為 `null`（VDA 不可能為 0，雙重保護）

2. **與 HSF 取平均值**
   ```
   收集所有非 null 的（主稽核分數、HSF）
   有 VDA 時: auditComponent = (VDA + HSF) / 2
   沒有 VDA 時: auditComponent = (QSA + HSF) / 2
   若 HSF 為空，則僅取 VDA 或 QSA
   ```

3. **預設值**
   ```
   如果都沒有:
     auditComponent = 0
   ```

### 二、年度分數計算

**計算公式（SQM 和 OSAT 相同）：**

```
如果 monthlyAssessmentSummary === null:
  annualScore = null

否則:
  如果 auditComponent === 0:
    年度分數 = 月考核平均分數 - others
  否則:
    年度分數 = (月考核平均分數 × 0.9) + (年度稽核組件 × 0.1) - others
```

**說明：**
- 如果沒有年度稽核分數，只根據月考核分數計算（不扣分）
- 如果有年度稽核分數，月考核分數佔 90%，年度稽核組件佔 10%
- 最後扣除 others 值

### 三、年度等級判定

**判定規則（SQM 和 OSAT 相同）：**

```
如果 annualScore === null:
  grade = null

否則:
  annualScore >= 95 → A
  annualScore >= 85 → B
  annualScore >= 75 → C
  annualScore >= 60 → D
  annualScore < 60  → E
```

## 差異對比

### SQM vs OSAT 主要差異

| 項目 | SQM/VQM | OSAT |
|------|---------|------|
| **月評核品質計算** | 品質基數評分 = 90 - 扣分項 | 進料允收率 + 基礎評分 |
| **月評核採購計算** | 相同公式 | 相同公式 |
| **月評核降級判定** | 總品質評分 < 56 或 交期評分 < 16 | 考核得分 < 60 |
| **年度稽核組件** | 相同邏輯 | 相同邏輯 |
| **年度分數計算** | 相同公式 | 相同公式 |
| **年度等級判定** | 相同規則 | 相同規則 |
| **下年度稽核計畫判定** | 根據供應商類型 + 單一維度 | 根據交易月數 + 交易總量 + 年度等級 |
| **稽核類型數量** | 3 種 | 5 種 |
| **供應商類型判斷** | 硬編碼清單 | 不區分國內外 |
| **下年度稽核計畫保存** | 前端計算並保存到資料庫 | 前端計算但不保存（僅顯示用） |

## 注意事項

### 1. 數據精度
- 後端計算：四捨五入至小數點後 3 位
- 前端計算：四捨五入至小數點後 2 位或 3 位（依模組而定）

### 2. 空值處理
- `receivedBatches === 0` 時，相關計算欄位返回 `null`
- `monthlyAssessmentSummary === null` 時，`annualScore = null`，`grade = null`

### 3. VDA 特殊處理
- `VDA = 0` 視為 `null`（VDA 不可能為 0，雙重保護）
- 只有在 `VDA > 0` 時才使用 VDA 作為年度稽核組件

### 4. 下年度稽核計畫判定
- **SQM**：前端計算並保存到資料庫，後端也計算（已統一邏輯）
- **OSAT**：前端計算但不保存（`setNextYearAuditType` 是空函數），僅顯示用
