# 供應商情報系統 — 產品藍圖（以供應商為中心）

> 定調日期：2026-07-30
> 核心轉變：**從「功能各自為政」→「以供應商為中心」**。評比、背調、比價、AI、分析不再是孤島，全部圍繞「一家供應商」匯流。

## 問題 → 解法對照

| 原問題 | 根因 | 解法 |
|--------|------|------|
| 評比像交差、不專業 | 只有「一張大表大家一起填」 | 供應商檔案 + 單家評比引導流程 |
| 主管想看一家公司過往/排名/類別 | 沒有「一家公司」完整視圖 | **供應商檔案（360）** |
| 背調獨立很怪 | 背調是孤島 | 背調併入供應商檔案/評比流程 |
| 比價太手動、看不出價值 | 沒接上評分/背調 | 比價候選帶出評分+等級+背調，逐維度標最優 |
| AI 很虛、沒整合 | AI 是獨立聊天孤島 | AI 嵌入檔案/報告（AI 綜合評估）+ 浮動助手 |
| 系統管理不直覺 | 純 UI | UI 打磨 |
| 登入該看什麼 | 沒分角色 | 角色首頁（看數據 vs 評比） |

## 目標架構

```
登入 → 依角色落地
  ├ 評比人員 → 評比工作台（本季待辦/進度 + 「評這家」入口）
  └ 主管/看數據 → 供應商情報概覽（異常/變化/排名 + 進入某家檔案）

★ 供應商檔案（Supplier 360）← 系統心臟
   基本資料 + 類別/地區 + 當前等級與排名 + 歷史評比趨勢
   + 背調 + 參與過的比價 + AI 綜合評估

功能頁
  ├ 評比：① 單家評比（專業引導）② 批量快速錄入（效率工具）
  ├ 比價尋源：結合評分+背調的選商決策工具
  ├ 分析中心：多維分析（圖表修成看得出差異；聚焦區間/環比/離群）
  └ 系統管理：供應商/帳號/評分設定（UI 打磨）

AI：不獨立成頁 → ① 嵌入檔案/報告的「AI 綜合評估」② 隨處可問的浮動助手
```

## 建置順序
1. **供應商檔案（360）** ← 先做，CP 值最高（一次解背調孤島/主管看過往/評比不專業/AI 整合的基礎）
2. 角色首頁（評比人 / 主管）
3. 評比流程升級（單家引導 + 批量）
4. 比價接情報 + AI 嵌入
5. 分析圖表修正 + 系統管理 UI 打磨

## 評比流程（兩種情境）
- **單家評比（專業）**：選一家 → 引導填品質/服務/交期（+背調）→ 當下看到算出的分數、跟自己歷史比、目前排名。
- **批量快速錄入**：現有大表，定位成「一次補很多家」的效率工具；「帶入上一季」放這裡才合理。
